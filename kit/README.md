# Whisper-диктовка

Местное распознавание речи на кнопке для **Arch Linux / KDE Plasma (Wayland)**.
Работает полностью офлайн: никаких облаков, ничего не улетает в сеть.

**Цикл работы:** «бип» → говоришь → «бип» → через пару секунд текст уже в буфере
обмена → вставляешь куда угодно (Ctrl+V).

---

## Что это и как работает

| Компонент | Роль |
|---|---|
| `whisper-cpp` | движок распознавания (официальный пакет Arch) |
| `ggml-cpu` / `ggml-vulkan` | вычислительные бэкенды (CPU / Intel Arc GPU) |
| `wl-clipboard` | кладёт текст в буфер обмена |
| `ggml-large-v3-turbo-q8_0.bin` | модель Whisper large-v3-turbo, 8-бит, 874 МБ |
| `whisper-dictate` | скрипт-«кнопка»: бипы, запись, запуск движка |
| `beep_*.wav` | звуковые подсказки начала/конца записи |

### Алгоритм скрипта

1. Первый запуск → звучит стартовый «бип», включается запись с микрофона
   (`parec` → `ffmpeg`, 16 кГц моно).
2. Второй запуск → «бип» стоп, запись прекращается.
3. В память загружается модель, `whisper-cli` распознаёт (~1–4 сек).
4. Текст → буфер обмена + уведомление KDE + файл `history.txt`.

### Почему ничего не висит в фоне

Микрофон захватывается **только** между двумя «бипами». В остальное время ни один
процесс Whisper не запущен, память не тратится. Модель (874 МБ) грузится в RAM только
на время распознавания и сразу освобождается.

| Состояние | Процессы | RAM |
|---|---|---|
| покой | — | 0 |
| диктовка | `parec` + `ffmpeg` | ~30 МБ |
| распознавание | `whisper-cli` + модель | ~1 ГБ кратко |
| после | — | 0 |

### Куда уходит текст

Только в буфер обмена и уведомление. В сеть — никогда.

## Установка

Требования: Arch Linux, рабочий KDE/Plasma (Wayland), микрофон, доступ к `sudo`.

### Способ 1. Инсталлятором

```sh
cd <путь к этому набору>
chmod +x install.sh uninstall.sh
./install.sh
```

Скрипт сделает 4 шага: пакеты → директории → скрипт+звуки → модель (874 МБ).
Всё, что он ставит, — официальные пакеты Arch и файлы этого набора.

### Способ 2. Вручную

```sh
sudo pacman -S whisper-cpp ggml-cpu ggml-vulkan wl-clipboard
mkdir -p ~/.local/bin ~/.local/share/whisper/{models,tmp}
install -m 755 whisper-dictate ~/.local/bin/
install -m 644 beep_start.wav beep_stop.wav beep_err.wav ~/.local/share/whisper/
curl -L -o ~/.local/share/whisper/models/ggml-large-v3-turbo-q8_0.bin \
  "https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q8_0.bin"
```

## Как пользоваться

```sh
# 1	й запуск — начать запись	(бип)
~/.local/bin/whisper-dictate
# говоришь...
# 2	й запуск — распознать	(бип, ждёшь ~1–4 сек)
~/.local/bin/whisper-dictate
```

Далее `Ctrl+V` — текст вставляется в любое поле.

Советы:
- Говори разборчиво, естественными паузами — распознавание чище.
- Английские кодовые термины вроде `git commit`, `async` распознаются отдельно
  (список «горячих слов» в начале `whisper-dictate`, переменная `HOTWORDS`).
- История распознанного: `~/.local/share/whisper/tmp/history.txt`.

### Горячая клавиша

Встроенных пользовательских ярлыков в Plasma 6 нет — глобальная клавиша требует
маленького фонового слушателя. Пока она не добавлена, вызывай скрипт вручную или
свяжи в KDE: Системные настройки → Персонализация → Клавиатура → Клавиши →
(для X11-совместимых окружений) либо через готовый фронтенд (Speech Note / Voice Control).

## Проблемы

- **«Ничего не распознано»** — слишком тихо/тишина, либо микрофон не тот (проверь
  `pavucontrol` → Вкладка «Запись»).
- **Паузы в записи** — запись останавливается только вторым нажатием (или сама через 120 с).
- **Другая точность/скорость** — замени имя модели в `HOTWORDS`-блоке: `small`
  (быстрее, слабее) или `medium` (компромисс). Модели качай из
  `huggingface.co/ggerganov/whisper.cpp`.
- **Качество русской речи** — убедись, что язык `-l ru` в скрипте.

## Удаление

```sh
./uninstall.sh
```
