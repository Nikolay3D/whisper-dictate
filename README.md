# whisper-dictate — проект голосовой диктовки

Локальное распознавание речи на «кнопке» для **Arch Linux / KDE Plasma (Wayland)**:
нажал → говоришь → нажал → текст в буфере обмена. Русский + английские кодовые термины.

## Структура проекта

```
whisper-dictate/
├── kit/            — установочный набор (готовые файлы для разворачивания)
│   ├── README.md        — как это работает, как ставить, как пользоваться
│   ├── install.sh       — установка в один запуск (пакеты + модель + скрипт + звуки)
│   ├── uninstall.sh     — удаление с показом удаляемых путей
│   ├── whisper-dictate  — главный скрипт-«кнопка» (запись + распознавание)
│   └── beep_*.wav       — звуки начала/конца записи
└── src/            — исходники демона горячей клавиши + оверлея
    ├── whisper-hotkeyd.cpp  — KGlobalAccel: ярлык Ctrl+E + анимация записи
    ├── CMakeLists.txt
    └── whisper-hotkeyd.desktop
```

## Как это работает (схема)

```
Ctrl+E ──▶ whisper-hotkeyd (демон, ~несколько МБ) ──▶ whisper-dictate
                                                            │  бип
                                            ┌───────────────┘  микрофон открыт
                                            ▼
                           parec ──▶ ffmpeg ──▶ record.wav
                                            │
                              Ctrl+E (2-й раз) ──▶ whisper-dictate
                                            │  бип, модель в RAM (~874 МБ, 1–4 с)
                                            ▼
                             whisper-cli ──▶ текст ──▶ буфер обмена (+KDE-уведомление, history.txt)
```

- Модель грузится в память **только** на время распознавания, потом освобождается.
- Микрофон захватывается **только** между первым и вторым нажатием.
- В сеть ничего не уходит.
- Оверлей (анимация записи) появляется только пока идёт запись.

## Сборка демона

```sh
cd src
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
install -m755 build/whisper-hotkeyd ~/.local/bin/
```

## Установка набора

```sh
cd kit
./install.sh      # пакеты + модель + скрипт + звуки
```
